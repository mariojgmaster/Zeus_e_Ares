# MVP 0.33.2 — Underwater Optics
A referência visual aprovada foi reproduzida com os próprios recursos independentes da demonstração. A branch parte de 0.32.3, sem promover os PRs à master. 12 WebP versionados com hashes Git coincidentes com o pacote local, 24 instâncias, 5 grupos de profundidade. Quatro planos navegáveis usam mapas RGBA de cobertura derivados da renderização efetiva dos objetos, em vez de máscaras manuais. Mantidos os modelos, texturas e motor biológico. Novo cenário padrão, com Natural e Clássico como alternativas. Óptica animada independente da geometria; a gradação de cor permanece quando o efeito dinâmico é desligado. WebGL acompanha a câmera; Canvas/Worker mantém posição estática para sincronização. Colisão aproximada por planos, sem geometria volumétrica real. Testes unitários da cena 6/6 executados localmente; verificação sintática do motor integrado em JavaScript. Build, smoke e Docker via CI; GPU física, comportamento de longa duração e homologação visual pendentes. Vegetação deformável fica para 0.33.3.
