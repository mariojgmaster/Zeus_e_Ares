# P1.2 — Intelligent Retained Rendering
Status: candidate. User approved implementation after P1.1 two physical reports (37.60 FPS native, 12.79 FPS full, zero >50ms in 1,578 native intervals). No claim of 60 FPS.
## Runtime
Opt-in /?retained=1, profile=balanced (default experimental), native, detail or max. Normal / unchanged. GPU Living remains reference; no Three.js or unified promotion. Profiles independently set tank 2D and habitat GL to native area, fish GL to 50% (balanced) or 75% (detail) of original capped DPR, foreground to half native linear scale. Native sets all native; max sets all 100%. CSS/UI/world/physics, fish mesh quality, atlas and original assets untouched. Reduced backing may soften image; not a silent quality downgrade. Explicit select and cache A/B toggle on experimental routes; FPS tooltip actual dimensions. Non-living/inspection fallback fish uses same backing as tank to preserve old composition. Full native alpha mask and existing collision reference unchanged; no reduction of depth precision. Optics and behavior remain enabled.
## Retained cache
Plan consecutive static runs by exact authored z/order, never across a plant. Merge only integer-positioned runs whose union pixel area does not exceed source sum and fits texture limits. Disjoint rocks stay separate if overdraw would increase. Bake tight transparent canvases once on first use from already graded sprites, upload persistent texture, release temporary canvas. Premultiplied-alpha source-over, common plane tint applied in existing shader; original draw list retained for immediate A/B. Same plant shader and wake indices; mask uses original sprites for exact alpha. No per-frame CPU raster or upload of cached runs. If allocation fails use original list; report actual retained flag. Cache stats builds, batches, saved draws, bytes; memory increases for cached textures, not full-plane targets. This is retained static subcomposition, not a cached whole scene framebuffer. Actual scene likely only two gravel pairs qualify; modest draw-call reduction, no predicted FPS gain. Fractional scaling can change bilinear alpha edges; human parity and tests required.
