# P1.3 — Optimized Optical Engine
Status: experimental candidate, 2026-11-26. P1.2 physical quick reference: balanced retained 45.81 FPS, 0/549 >50ms, p95 33.5ms; native-soft 45.58. Target 60 FPS not yet achieved.
## Architecture
Three independently selectable optical pipelines: reference (original), cached (Canvas2D), GPU+cache. No new context or surface, no reduction of fish/habitat/foreground backing from the selected P1.2 profile. Normal route unchanged; /?optical=1 selects GPU+cache and balanced unless profile explicitly chosen. All original controls, fish geometry/skins, plant deformation, native alpha mask, collision, feeding, particles, bubbles, ripples and biological state remain unchanged. Inspection, nonliving renderer or failed GPU/cache returns to original or cached. Actual mode exposed in selector/FPS and benchmark rejects fallback.
Cache: 256x256 combined veil+glow texture (original source-over order), strength quantized 1/128 with one resident entry and rebuild only on changed strength/config; nine 256x128 ray profiles (center pulse quantized within .0045; original time-based position/angle remains continuous), 128x128 radial shadow sprite, same source-over blend. Total 1.44 MiB raw RGBA cache (not measured driver residency). Surface photo and fine motes remain exact original draw code. Vignette retains existing cached gradient. No per-frame full-size optical bitmap or readback. During transitions the soft texture can rebuild; small quantization and filtering may create subtle differences, human parity required.
GPU: existing habitat WebGL context, single full-screen shader for vertical veil and five light cones. Two persistent texture uploads, premultiplied screen combination reproduces transparent overlay before source-over on opaque habitat. Skips original tank Canvas2D gradient and five cone draws when active. Shadows remain behind fish, night overlay and interactive elements unchanged; foreground remains Canvas2D for exact order of surface, particles and bubbles. This pass still costs fill rate; no claim faster until benchmark. Does not consolidate all canvases; no new renderer library. No change to resource loading or default Max. GPU precision/initialization failure fallback; context loss existing handling. 
## Benchmark
/?opticalLab=1, eight phases: balanced reference/cache/GPU; native-soft reference/GPU; detail reference/GPU; balanced reference repeated to detect drift. Retained cache always on, identical per-pair backing sizes, optics enabled, same current day/night, flow/depth. Quick 4+12s per phase (128s), extended 10+30s (320s), export aqua-optical-lab.json. Reports actual optical pipeline, cache counters, CPU submission for background light/front effects, optional async GPU optical pass timing separately from color and fish. CPU/GPU metrics not additive; compositor not timed directly. Repeat with actual day/night, extended x3 and soak before release; live fish paths unseeded. Synthetic framebuffer checks day/night, cached front, ray quantization and no rebuild at stable strength; browser integration checks mode, fish buffer, night/feed/inspection. Real scene visual parity and physical FPS still pending.
