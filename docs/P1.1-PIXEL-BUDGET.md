# P1.1 — Pixel Budget & Resolution Lab
Status: candidate; diagnostic, not a production performance fix. P0/P1 physical evidence in PERFORMANCE-P0-P1.md. Current GPU UHD 630, reported viewport 3278×1594 CSS, DPR 1.25 (~8.16 MP). P1 failed performance; leave default GPU living unchanged.
## Scope
Opt-in /?pixelLab=1, legacy /?lab=1 retained. Ten sequential phases: living animated 100/75/50% and native area; unified animated 100/75/50%; GPU static 100%; living 100% with existing optics toggle off; living 100% with only foreground Canvas2D at 50%. Native = min(1,sqrt(1672×941 / nominal backing pixels)); preserves aspect, not a fixed 1672×941 output. Device DPR capped at existing 1.5 before scale. Main backing scale applies tank Canvas2D, fish WebGL and visible habitat WebGL, foreground independently. Normal runtime remains 100%; no new default, no texture/mesh/asset modifications, no change to CSS/world or physics coordinates. Native mask stays native. Smaller output can soften final image; visual review required.
## Protocol
Quick 4s warm/12s measured ×10 (~160s); extended 10s/30s ×10 (~400s). One run per profile, user can repeat three times; same CSS viewport, depth and flow, current night setting, max quality, camera centered, controls locked and pointer interaction disabled. Reject changed viewport, device DPR, unexpected render mode, settings or backing size. Abort on hidden tab, photo or cancel; restore initial resolution, mode, optical switch and control interaction. Export local JSON schema 2, per phase actual backing sizes and WebGL drawingBuffer dimensions, DPR, scenario, FPS, p50/p95/p99, long frames, CPU submission and GPU async queries if supported. GPU context allocations from previous phases can remain; sequential stochastic trajectories and GPU thermals not controlled. Browser compositor is not directly timed. Optics OFF is existing control, not all optics/effects disabled. Foreground-only isolates raster backing cost, not compositor bandwidth entirely. For release repeat extended run ×3 and capture Chrome compositor trace if gap remains. No FPS inferred from pixel ratios. Original lab remains six modes.
## Tests
Pure dimension math, bounds, ten profiles and buffer validation; Playwright opt-in, real transition to 75% with unchanged CSS bounds, cancel restores state, resize abort. Actual 60 FPS, image fidelity, driver/refresh and release gate remain hardware-dependent. P1.2 static batching and P1.3 optical optimization only after results. No merge to master.
