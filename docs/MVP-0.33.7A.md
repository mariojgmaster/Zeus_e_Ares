# MVP 0.33.7A — GPU Static Scene
User approved ADR-008. Candidate, not homologated.
## Scope
Default-off A/B GPU Static toggle. Reuse the five native, graded and blurred static canvases generated once from original 12 WebP/24 instances, upload once into existing fish WebGL context, draw ordered premultiplied quads with same crop and camera factor. Generate four independent alpha channels in GPU framebuffer once, with authored top-row orientation; fish fragment shader samples this mask when GPU scene active. CPU static collision map remains unchanged. No changes to fish assets, mesh, behavior or optical/foreground effects.
## Transitional bridge
For strict layer order, static color pass shares fish context, then is copied into cached 2D background before fish pass; cache keyed by viewport/crop/camera, recomposed only on change. Existing 2D night/food/ripples and foreground optics remain as before. The bridge may involve browser-internal GPU/CPU copies on cache invalidation; no explicit readback in normal mode. Not final retained per-plant renderer. Stage B must move individual meshes and eliminate bridge where parity permits. Inspection uses original rendering, preserving blur. GPU static temporarily suspends vegetation without losing user's prior toggle; exiting restores it. Non-WebGL and context loss fall back to original. No changes to Natural/Classical.
## Tests / gates
Unit coordinate and pixel metric checks. Chromium SwiftShader synthetic alpha/color/orientation and real static background A/B pixel comparisons at desktop/mobile, with optional ?gpuParity=1 diagnostic readback (never normal runtime), plus mode/control smoke. Threshold proposals: alpha max 1, color mean <2.5/255 and <3.5% channel deltas >12; synthetic color max 3. Real human screenshots and GPU performance remain required; compare original with vegetation off to GPU static, same controls/viewport. Inspect color, leaf edges, fish occlusion, camera, day/night, food, observation, resize, context loss. Record FPS/renderer with same hardware. Do not mark full GPU architecture implemented: stage A is static planes + GPU mask, not individual plants or physical proxies. No merge before approval. Stage B only after visual gate.
